# 物理参数化预览：高含沙水体、极细砂床与两道倾斜石笼

这是一套可重复计算的先验参数，不是实测标定成果。没有输入河段水位、流速剖面、粒径筛分、含沙量时间序列或床面测量，不能反演确定石笼阻力与混合系数。

## 运行与查看

```bash
source activate_thetis.sh
python scripts/physical_preview.py
python -m http.server 8766 --bind 127.0.0.1 --directory outputs/physical_preview
```

打开 http://127.0.0.1:8766/ 。时间轴为已计算帧的回放，不是在浏览器中重新解算。流速与浓度显示各三角形的 DG0 平均，床面变化正值为淤积、负值为冲刷。全时段共用色标；原生 DG/CG 结果仍保存在 VTK 中。单元平均检查不能排除 DG 局部节点的负值，需同时检查原始自由度。

## 后续如何标定

1. 用实测水位差和石笼上下游流速约束阻力；保持流量与几何实测值固定。
2. 用示踪剂扩散或横向含沙剖面约束混合参数。
3. 用筛分与水温更新粒径、黏性；用采样含沙量设定边界时序。
4. 用独立时段的床面高程差检验沉积/冲刷，并核算累计边界泥沙通量。

目前全域床面可冲刷，包括石笼投影下方。真实基础防冲、有限可蚀层与结构失稳均未表示。不得直接把该结果用于石笼工程尺寸或安全判断。

## 数值求解修正

首次长时算例在耗尽区域出现约 −1.8e-9 m 的泥沙 q 负值。已将泥沙方程改用 MUMPS 直接线性求解，并设置 SNES 相对/绝对容差为 1e-9 / 1e-13，检查默认容差相对于 q≈1e-5 m 过大的可能影响；收紧容差后负值没有消失，因此不能把它归因于线性求解精度。保留原始输出，不作负值截断；每个导出帧记录原始 q 最小值，预览生成前检查单元平均浓度与水深。

另外将时间步由 0.25 s 减到 0.10 s 复算。页面显示实测负值幅度并保留有符号浓度色标；仅在负值幅度不超过入口浓度 0.1% 时允许生成探索性预览，这不是严格非负性的证明。若有负值，页面明确标注未通过严格非负性验收。

## 本次运行结果

2026-11-06 改为高含沙水体情景（1.0 kg/m³、0.063 mm）。此前 0.2 mm 砂配 0.1 kg/m³ 入流时，入流泥沙在入口 0.1 m 内全部沉积（入口列约 +1.6 mm）；改用平衡入流又等于把来水当作接近清水（约 0.005 kg/m³）。

60 s 耦合共导出 41 帧。D* = 1.594，沉降速度 0.003569 m/s，临界剪应力 0.15357 Pa；最小单元平均水深 0.5979 m。单元平均含沙量从入口 0.98 沿程降到出口 0.44 kg/m³。最终床面全域淤积 +0.131 至 +0.599 mm，沿程由约 0.37 降到约 0.26 mm。最大淤积在石笼 1 背水侧 (6.8, 2.8)；石笼投影区与背水区平均 +0.38 / +0.39 mm，高于其余区域的 +0.28 mm；最小淤积在石笼 2 与岸之间的束窄过流区。单元平均浓度与原始 q 均无负值。悬浮泥沙由 77.5 kg 降到 52.8 kg，床面净增 61.3 kg。页面保留这些值，严格非负性、完整质量收支与网格收敛尚未通过验收。
